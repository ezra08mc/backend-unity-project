# Backend Unity Project Documentation

This document provides a comprehensive guide for setting up, running, and interacting with the **Backend Unity Project**, a secure Todo List API built with Go, Gin, and PostgreSQL.

## 1. Overview
The Backend Unity Project is a RESTful API designed for task management. It follows Clean Architecture principles to ensure modularity and maintainability.

## 2. Prerequisites
Ensure your development environment has the following installed:
- **Go** (version 1.21 or higher)
- **PostgreSQL**
- **OpenSSL** (for generating JWT keys)
